# Languages of the web page

The page is written in English. A language file maps each English text to its translation:

- `index.json` lists the languages: `[{ "code": "de", "name": "Deutsch" }]`. `code` is the
  language tag the browser reports (`de`, `fr`, `pt-br` in lower case), `name` is shown in the
  System tab's language list.
- `<code>.json` holds `"English text": "translation"`. Texts that are missing or empty stay
  English. `{0}`, `{1}` … are filled in at run time and must stay in the translation.
- `template.json` lists every translatable text (generated by `node tools/i18n-keys.js`). It also
  contains the parameter and value names from `lib/schema.json`; RME's menu names can be left
  untranslated so they match the unit's display.

Adding a language:

1. Copy `template.json` to `<code>.json` and fill in the translations.
2. Add the language to `index.json`.
3. `node tools/i18n-keys.js <code>` lists texts the file lacks or no longer needs.

The language is chosen per browser under System → Language; without a choice the page uses the
first of the browser's languages that has a file. The bridge's own messages (errors from the API,
the log) and the Headphone EQ Generator (`/eq/`) are English.
